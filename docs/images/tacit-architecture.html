요청 흐름
  1. 1A가 DM에서 /tacit-send를 보내면 Slack이 커넥터로 전달합니다.
  2. 4worker는 게이트웨이 → Claude Opus 4.8로 초안과 해석을 요청합니다.
  3. 2커넥터가 relay에 작업을 등록합니다.
  4. 5A가 공유를 누르면 승인한 맥락만 relay를 거쳐 worker-b로 갑니다.
  5. 3worker-a가 원문 DM을 A 이름으로 보내고, 배경 초안을 A에게만 보여줍니다.
  6. 6worker-b가 B의 자료와 비교해 B에게만 보이는 설명이나 확인 질문을 올립니다.
데이터 원칙
  • 각 worker는 자기 사용자 자료와 그 DM방 기록만 읽습니다.
  • 승인 전 초안은 worker 볼륨에만, relay에는 해시값만 갑니다.
  • 되묻는 질문에는 원문과 이미 공유한 내용만 들어갑니다.
  • API 키와 토큰은 서버 설정 파일에만 있습니다.
